# EzUmrah

Cloud Travel CRM for Umrah & Hajj Agencies — Built with Next.js 14, TypeScript & Tailwind CSS.

## Features

- 🕐 Bilingual (English/Arabic) with RTL support
- 📊 8 CRM module showcases
- 💳 3-tier pricing
- 🔌 GDS integration showcase (Amadeus, Sabre, Galileo, Travelport)
- 📝 Formspree contact form
- 🔍 Full SEO: schema.org, sitemap, robots, OG tags
- 🎨 Dark midnight + gold/teal theme
- ⚡ Vercel-optimized

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

Deploy on Vercel — just connect this repo and deploy.
